# AviationSAR – Aviation Search and Rescue

## Project Overview
AviationSAR is a decision-support framework for aircraft search-and-rescue analysis using aircraft trajectory data, search-priority assessment, UAV mission planning, and machine-learning-based rescue outcome prediction.

## Main Modules
- Aircraft trajectory data processing
- Search-priority classification
- UAV mission assignment and route planning
- Rule-based rescue decision support
- Random Forest rescue outcome prediction
- Weather-aware risk assessment
- Result visualization and evaluation

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib

## Dataset
The current experimental evaluation uses 57 aircraft records. The project analyses the available dataset and generates decision-support outputs.

## Source Code
The Python source files for the AviationSAR project are maintained in this public GitHub repository.

## Disclaimer
This is a research prototype for decision support. Results from the experimental dataset should not be interpreted as proof of real-world rescue performance.
